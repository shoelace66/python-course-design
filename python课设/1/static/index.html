05

算法原理与帮助

答辩时可以直接打开本页讲解系统设计

ABOUT THE PROJECT

用透明算法
理解音乐信号

MusicScope 采用 Python 标准库从零实现音频特征分析。不依赖云服务，所有算法均可在源代码中追溯。

analysis_pipeline.py
WAV → PCM samples · frame + Hann window · FFT / autocorrelation · feature fusion · SQLite transaction
01RHYTHM

节奏 BPM

计算短时 RMS 能量，对能量上升沿构造起音包络，再用自相关寻找最稳定的周期，换算每分钟节拍数。

BPM = 60 × frame_rate / lag
02PITCH

音高与音名

在有效声音帧上计算归一化自相关，以最佳延迟估计基频，再用十二平均律把 Hz 转换为音名。

MIDI = 69 + 12 log₂(f / 440)
03VOLUME

响度 dBFS

由原始采样直接计算 RMS 与峰值，不做整体归一化，因此能够保留不同文件之间真实的音量差异。

dBFS = 20 log₁₀(RMS)
04TIMBRE

频谱与调性

Hann 窗配合 1024 点 FFT 得到频谱；聚合十二音级能量，并与大小调模板做相关匹配。

Chroma + key profile correlation
05CLASSIFY

听感分类

融合 BPM、dBFS、频谱重心和动态范围，输出可解释的规则标签与匹配度，不伪装成机器学习概率。

fast + loud → 激情动感
06DATABASE

数据库持久化

轨道、分析、特征和分类使用外键关联；一条分析在同一事务内完成，删除时级联清理关联数据。

SQLite + FK + transaction

使用步骤

  1. 双击项目根目录的“一键启动.bat”。
  2. 在“音乐分析”中选择 PCM WAV，或点击生成演示音频。
  3. 等待本地算法完成，查看指标、波形、频谱与十二音级图。
  4. 在“分析记录”恢复历史结果，在“数据管理”导出或导入数据库内容。
