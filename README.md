# Python 课程设计合集

本仓库按照课程目录组织：

```text
python课设/
└─ 1/
   └─ MusicScope 音乐特征分析器完整项目
```

## 下载后直接演示

1. 点击 GitHub 页面右上角 **Code → Download ZIP**。
2. 解压仓库，进入 `python课设/1/`。
3. Windows 双击 `一键启动.bat`。
4. 浏览器自动打开后，点击“生成演示音频”，即可展示分析、可视化、分类、SQLite 入库及数据导入导出。

运行环境只需要 Python 3.10 或更高版本，不需要安装第三方库。

如果只想下载单个完整课设包，也可以直接下载：

`python课设/1/MusicScope_音乐分析器_课程设计.zip`

项目说明、课程设计报告和答辩提纲均位于 `python课设/1/`。
